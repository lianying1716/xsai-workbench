FAQ

部署之前，
你可能想知道

星采是 SaaS 吗？

不是。星采只提供私有化部署，不提供统一线上服务，也不需要注册。你可以先打开在线演示看看完整界面与数据形态，再把它部署到自己的电脑、服务器或内网环境里。

产品收费吗？

产品免费。采集、下载、转录、素材库、API / MCP 都在你部署的实例里运行。AI 分析需要模型，可以接自己的 OpenAI 兼容接口，也可以用本地模型。

需要什么运行环境？

支持 Linux、macOS、Windows 单机部署。首选 Docker Compose，数据库用 PostgreSQL；预处理视频需要 ffmpeg，本地转录需要 faster-whisper 模型。

它怎么拿到我的收藏和关注？

登录你自己的平台账号后，星采通过平台原生接口或浏览器流程读取关注列表、收藏夹和作品数据。凭证 AES-256-GCM 加密存储，接口与前端只返回脱敏值。

可以只采集关键词，不导入账号吗？

关键词采集同样需要对应平台的登录态，因为平台接口要求已登录。你可以创建一个专用账号，只在星采里用于采集。

评论会全部抓吗？

不会。默认只有达到热度门槛的作品才触发评论抓取，抓取页数、条数和频率都可配置。

能把素材喂给我自己的 Agent 吗？

可以。在「AI 接入」页创建带权限范围的 API Key，然后通过 HTTP API 或 MCP 调用：搜索素材、取转录、触发同步、运行采集和导出。
