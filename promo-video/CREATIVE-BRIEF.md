# 星采宣传片 · 创作稿 v2（文案 / 分镜 / 视觉语言）

> v1 的问题（用户反馈）：① 痛点文案没感觉 ② 功能点太少 ③ 界面缩放不够、只有图片没有点击
> ④ 音乐太快、动效不够。
> v2 重写三件事：**一句话戳中要害的文案**、**逐控件级的真实交互演示**、**更克制的音乐与更大的动作**。

---

## 一、核心主张

**主标语（收尾 CTA）**
> 你存的不是内容，是待还的债。星采，把它变成你的资产。

**一句话定位（贯穿全片）**
> 自媒体人的内容资产库：六个平台的收藏、点赞、关注，自动变成可检索、可复用的内容。

**为什么这句比 v1 好**
v1 说"收藏夹正在变成坟场"——是描述现象，观众点头但无感。
v2 说"你存的不是内容，是待还的债"——把收藏的**负罪感**点出来。每个刷到好内容就存、再也没打开的人，都有这本债。痛点从"东西乱"升级为"我欠自己"。

## 三、视觉语言

### 沿用（产品自己的设计系统，不改）
- 米白 `#FFFDF8` / 炭黑 `#16151A` / 砖红 `#C13A2C` / 蓝 `#2249C9` / 黄 `#EEB51B` / 绿 `#1E7A4D`
- 硬描边（0.4cqw）+ 硬偏移阴影（无模糊）
- 中文标题用得意黑，正文 Noto Sans CJK SC，标签 JetBrains Mono

### 新增（针对 v1 的"动效不够"）
1. **真实鼠标指针**：所有交互镜头带一个可见的光标，移动到目标、点击、有按下反馈。这是"真的在操作"而不是"图片在动"。
2. **点击涟漪**：每次点击有从光标散开的圆环 + 目标元素轻微下压。
3. **输入打字**：关键词输入框真的逐字打出来（不是直接显示结果）。
4. **面板推入**：详情抽屉从右侧滑入并有轻微透视，不是淡入。
5. **数据流**：转录文本逐行浮现，带光标闪烁。
6. **镜头推近（更强）**：从整屏缩放到具体控件区域，缩放比 v1 大（1.25–1.6 倍），并配缓动。

### 节奏（针对 v1 的"音乐太快"）
- 换更稳的曲子：**96–104 BPM**（v1 是 123），更符合"内容资产"的沉稳气质。
- 动作更大、更少：每个功能点一个完整动作（移动 → 点击 → 反应），而不是碎动作堆叠。
- 留白：每次点击后留 0.3–0.5s 让画面反应完，再进下一个。
