# 公网独立演示站（静态、只读）

## 目标

给外部用户一个可以“直接点开就能逛”的产品演示：不登录、不依赖后端、不写任何数据。
用于宣传、售前演示和内部评审，而不是生产工作台。

## 形态

- **完全公开**：一键进入，无登录、无口令。
- **纯静态**：`GET` 走本地 JSON 快照，媒体走本地文件；页面不发起任何外部请求。
- **只读**：所有写操作（新增 / 编辑 / 删除 / 重试 / 检测）统一提示「演示站为只读展示，数据不可修改」。
- **可点击**：页签、筛选、分页、详情抽屉、视频播放、调用审计链路都能真实操作。
- **全导航保留**，关键页面有完整演示数据；设置类页面只读展示。

## 构成

| 部分 | 文件 |
|------|------|
| 演示数据种子 | `scripts/seed_demo.py` |
| 快照导出 | `scripts/export_demo_snapshot.py` → `web/public/demo-data/` |
| 前端演示运行时 | `web/src/demo/runtime.ts` |
| 演示构建 | `npm run build:demo` → `web/dist-demo/` |
| Nginx 托管 | `deploy/nginx/demo.conf` |

## 使用方式

```bash
cd platform-api
uv run python scripts/export_demo_snapshot.py   # 重置演示库并导出快照
cd web && npm run build:demo                    # 产出 dist-demo/
```

演示构建默认使用 `/demo/` 子路径（`vite.config.ts` 里按 `VITE_DEMO_MODE` 切换 `base`），
因为线上是挂在官网落地页 `cai.xsai5.xyz` 的 `/demo/` 下。

### 线上部署（当前线上形态）

- 落地页：`https://cai.xsai5.xyz/`（`site/`，香港服务器 `/var/www/cai`）
- 在线演示：`https://cai.xsai5.xyz/demo/`（`platform-api/web/dist-demo/` → `/var/www/cai/demo/`）
- 落地页 PC / H5 顶部导航、首屏、CTA、FAQ 与页脚都有「在线演示」入口。
- Nginx 配置见 `/etc/nginx/sites-available/cai.xsai5.xyz.conf`（香港服务器），
  仅静态发文件，没有任何反代。

演示站没有任何 API，`/api/` 不参与；如果单独托管，套用 `deploy/nginx/demo.conf` 即可。

## 边界

- 快照是演示数据的只读副本；新增前端接口时，需要同步更新
  `scripts/export_demo_snapshot.py` 的抓取路径后重新导出。
- 演示模式不引用任何外部图床 / 头像地址，避免静态站出现破图和外部请求。
- 生产工作台布局不受演示站的窄屏适配影响。
