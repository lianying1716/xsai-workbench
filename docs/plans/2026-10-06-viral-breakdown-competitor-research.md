# 爆款拆解 + 对标账号拆解 —— 成熟方案调研

> 日期：2026-10-06
> 目的：在动手做「爆款拆解报告」与「对标账号拆解」之前，先看成熟产品到底展示什么内容。
> 结论：市场已分成三条清晰的产品线，且「拆单条爆款」与「盯对标账号」是两个独立但可打通的产品。

---

## 一、产品线划分（竞品地图）

| 线路 | 代表产品 | 核心动作 |
|---|---|---|
| **A. 单条爆款拆解** | ViralDrop、Inflowave、Viralo、Brieflee、HookScan/HookMaster/Shorta/Tikalyzer、Contentine、**蝉妈妈「AI拆视频」** | 贴一条链接 → 拆解"为什么火" → 给复刻蓝图 |
| **B. 对标账号追踪** | ViralDrop Tracker、FYPNow、ViralTrack、Catch&Release、TubeAnalytics、vidIQ Trend Alerts | 盯一批账号 → 爆款breakout 提醒 + 周报 |
| **C. 企业级声量/竞品** | Brandwatch、Sprout Social、SocialInsider、Hootsuite | 份额声量、情感、受众画像、内容缺口、投放复盘 |

## 二、线路 A：单条爆款拆解——他们都展示什么

### 2.1 拆解维度（横向合并所有产品的字段）

| 维度 | 具体内容 | 出处 |
|---|---|---|
| **黄金 3 秒 Hook** | 钩子类型（好奇缺口 / 反常识 / 清单体 / 转变叙事 / 痛点直呼）、首帧画面、首句台词、首屏文字、为什么抓人 | Inflowave、WaveVision、HookScan |
| **内容结构** | 钩子→铺垫→高潮→CTA 的分段与各段作用 | ViralDrop、蝉妈妈 |
| **节奏与留存** | pattern interrupt（每 3–5 秒一个变化）、留存钩子（视觉loop/回调/beat-drop/层层兑现）、8 秒与 12–18 秒的二次拉回 | Inflowave、Viralo |
| **心理触发** | 用了哪些心理杠杆（好奇、认同、损失厌恶…） | ViralDrop |
| **剪辑风格** | 剪辑节奏、卡点、字幕时机 | WaveVision、蝉妈妈 |
| **CTA** | 引导方式与位置 | ViralDrop、Inflowave |
| **文案/脚本** | 逐句文案、可复用句式、金句 | 蝉妈妈、ViralDrop |
| **评分** | Hook Score / Retention Score / 爆款指数（0–100 或 1–10） | WaveVision、Viralo、HookScan |
| **留存曲线预测** | 预测留存曲线 + 标注**掉粉秒数** + 修复建议 | Retensis、Shorta、HookMaster |
| **时间戳级反馈** | "把最强画面挪到第 1 帧"、"0:07 处切掉" | HookMaster、WaveVision |
| **复刻蓝图** | 步骤化套用到自己选题（不是"欣赏"，是"可执行步骤"） | Inflowave、ViralDrop |
| **转录全文** | 带时间轴字幕 | ViralDrop、Brieflee |

### 2.2 蝉妈妈「AI拆视频」的本土口径（最贴近我们）
- 拆解维度：**文案 / 分镜 / 脚本 / 画面 / 评论**五大维度
- 强调：黄金 3 秒台词设计、镜头切换节奏、情绪钩子
- **关键分工**：`AI拆视频` 只做**内容逻辑拆解**；**5 秒完播率、受众画像（性别/年龄/地域）**在「视频详情页-基础分析/观众分析」里看。
  → 即：**内容拆解** 与 **数据指标** 是分开的，但在同一详情页组合成"数据定位 + 内容拆解"复盘闭环。

### 2.3 行业公认的"为什么会火"五要素（Inflowave 总结）
1. 钩子够强，过掉 **3 秒跳出**
2. 早期兑现升级（第 8 秒前让观众获得奖励）
3. **12–18 秒的二次拉回**（第二次最大流失点）
4. 高回放性（结尾自然带回首帧，可循环）
5. 强评论钩子（一个让人忍不住回复的观点/问题）

## 三、线路 B：对标账号追踪——他们都展示什么

| 能力 | 具体做法 | 出处 |
|---|---|---|
| **爆款 Breakout 提醒** | **双条件**：与上一条快照比增速快 **且** 相对该账号自身中位数是离群值（避免大号普通内容误报） | FYPNow |
| **刷新节奏** | 全量每日 1 次；近 7 天内容每日 4 次 | FYPNow |
| **邮件摘要** | 爆发即时邮件 + 应用内 "Breaking out" 信息流 | FYPNow、ViralTrack |
| **周报** | 每个对标账号：涨了多少播放/互动、新发布、爆款 | FYPNow |
| **账号级内容分析** | hooks、封面、节奏、内容结构、呈现风格（可分析整个频道） | Contentine |
| **内容支柱（pillar）** | 把对标账号内容归类成支柱，看它主打什么 | SocialInsider |
| **内容缺口（gap）** | 对标做过、你没做的**选题/格式** → 直接变成你的选题日历 | SocialInsider、PostEverywhere |
| **发布节奏 / 最佳时间** | 一周哪天、几点发 | Hootsuite、Later |
| **互动基准** | 用"自己近 3–6 个月同类内容的中位数"作对照，而非行业平均值 | TopMarketingFunnels |
| **里程碑/增长提醒** | 发布新视频、涨粉到某个量级、爆发增长 | TubeAnalytics |
| **声量/情感/受众重叠** | share of voice、sentiment、audience overlap（企业级） | Brandwatch、Sprout |

## 四、我们的现状 vs 竞品（差距分析）

**我们已经有的原料（这是别人没有的优势——数据在自己库里）：**
- 转录（带时间轴）、视频理解（类型化多维）、评论正文+昵称+点赞、跨平台互动快照趋势、作者维度聚合、订阅（关注博主）。

**可直接补齐的展示（几乎零新数据）：**
- Hook 拆解、结构拆解、评论洞察、复刻蓝图、单条爆款指数。
- 对标账号：发布频率、Top 作品、选题聚类、发布时段、互动中位数、内容缺口。

**需要补的底层数据/能力：**
1. **粉丝数快照**（现在 `content_metric_snapshot` 只有播放/赞/评/藏/转，没有账号粉丝数）→ 涨粉趋势、账号体量对比需要。
2. **单条内容的"增速"**（需要多次快照 + 时间差；我们现在有快照但不一定有足够频次）→ breakout 双条件需要。
3. **爆款指数/评分模型**（可先用规则+分位，后接大模型）。
4. **（可选）场景切换/节奏的精确量化**——抽帧档已按你的要求删除，但"镜头切换节奏"若要精确到秒，需要轻量场景检测作为**拆解内部子步骤**（非用户可见档位）；不做也能靠视频理解模型定性给出。

## 五、建议的产品形态（两份可打通）

### 功能 1：单条爆款拆解报告（爆款拆解）
一条作品 → 一份报告，展示：
1. **一句话结论 + 爆款指数**（vs 账号中位数）
2. **黄金 3 秒**：台词 / 画面 / 钩子类型 / 为什么抓人
3. **内容结构**：分段 + 每段作用（钩子-展开-转折-高潮-CTA）
4. **节奏与留存**：pattern interrupt、二次拉回点、情绪曲线
5. **文案拆解**：可复用句式、金句
6. **评论区洞察**：高频词、争议点、观众最关心的问题（我们独有）
7. **数据表现**：互动率、相对账号中位数
8. **复刻蓝图**：步骤化套用你的选题
9. **一键用星算生成同结构脚本**（内置 AI 落点）

### 功能 2：对标账号拆解（对标账号）
选定对标账号 → 一份账号分析，展示：
1. **账号概览**：发布频率、平均互动、涨粉趋势
2. **内容支柱**：它主打哪些选题/形式（聚类）
3. **爆款规律**：Top N 作品的共性（钩子/选题/时长/发布时段）
4. **发布节奏**：一周哪天、几点发
5. **内容缺口**：它做了、我没做的选题/格式
6. **对标自己**：我的指标 vs 它的中位数
7. **爆款提醒**：某条超过其自身中位数 N 倍 → 通知（双条件）

> 两者关系：账号级分析 = 单条拆解的聚合；单条拆解 = 账号级分析的"证据"。可先做单条拆解（原料全在、见效快），再做账号级聚合。
